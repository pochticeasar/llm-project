# Блок Б: локальный и глобальный поиск

`local_search` распознаёт коды и названия без модели. При нескольких опорных сущностях
использует все простые пути до трёх рёбер в неориентированном графе, затем проходит
направленные цепочки замены. Для одной сущности берёт рёбра в пределах двух шагов.
В запрос к модели попадают только отобранные направленные факты, общим объёмом до
8000 символов. `Answer.facts` содержит переданные факты, а `Answer.sources` — документы
рёбер, вошедших в запрос. Неизвестный код или отсутствие фактов дают отказ без LLM.

В составном вопросе о детали, цене и остатке модель может отказаться из-за отсутствия
данных ERP. Если граф нашёл деталь модели или цепочку `REPLACED_BY`, возвращаются сами
отобранные факты с `refused=false`: агент может использовать их для поиска детали,
а цену и остаток получить отдельно. Такой ответ не содержит данных ERP и не гарантирует,
что модель агента правильно выберет замену.

## Пример: подбор замены

Для вопроса «Какую деталь заказать при E-17 на AR-210?» коды E-17 и AR-210
становятся опорными сущностями. Среди найденных фактов графа:

```text
E-17 -INDICATES-> пусковое реле
AR-210 -HAS_PART-> P-1042
P-1042 -IS_A-> пусковое реле
P-1042 -REPLACED_BY-> P-1042B
```

Последняя связь дополняется при обходе цепочки замен. Ответ может назвать P-1042B;
его источники включают руководство AR-210 и бюллетень замены. Если в тот же вопрос
добавить цену и остаток, за их получение отвечает агент через ERP, а не этот поиск.

`global_search` делает map по каждой сводке с JSON-схемой `MAP_SCHEMA`, игнорирует
невалидные или бесполезные ответы и объединяет остальные одним вызовом reduce.
В reduce передаются ответы map и исходные сводки полезных сообществ, чтобы сохранить
числа и обоснование. Источники берутся из узлов, рёбер и связей с линейками этих сообществ; это документы
сообщества, а не доказательство каждого утверждения итогового ответа.
В источники также входят документы связей замен и моделей, добавленных в контекст
сводки через границу сообщества. Список может быть шире фактов итогового ответа.
Сумма весов рёбер не обязательно равна числу уникальных фрагментов: один фрагмент
может подтверждать несколько связей. Её также нельзя считать числом инцидентов.
