# Блок Б: сообщества и сводки

`communities.py` строит неориентированный граф для алгоритма Лувена, суммируя веса
встречных связей, и возвращает воспроизводимое разбиение. Сводка использует внутренние
рёбра сообщества, входящие отказы узлов и связи моделей с линейками за его границей; код заранее суммирует веса
`FAILED` для каждого узла и отдельно для каждой линейки. Модель выбирает
строки для сводки; код сохраняет только точные факты из графа и подсчёты. Если модель
не выбрала допустимых строк, используется список фактов. Вес означает
количество подтверждающих фрагментов, а не обязательно число инцидентов. Для сообщества
без связей неподтверждённые выводы модели заменяются сообщением об отсутствии связей.

Для замен деталей в сводку также включается контекст за границей сообщества:
связь `REPLACED_BY`, модели с этой деталью (`HAS_PART`) и их линейки
(`BELONGS_TO`). Это позволяет соотнести снятую деталь с линейкой, когда узлы
разбиты по разным сообществам. Длина сводки по-прежнему ограничена 150 словами,
поэтому сохранение всех таких связей в крупном сообществе не гарантируется.
Для сравнения моделей код также суммирует веса их исходящих связей `FAILED` по
всему графу, включая связи за границей сообщества. Это сумма весов, а не число
инцидентов или уникальных фрагментов.


Контекст и формат передачи: [communities_and_search.md](communities_and_search.md). Проверки: [tests/block_b](../../../tests/block_b/README.md).
